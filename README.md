## Featured Network Engineering Projects

### [cisco-netaudit-engine](https://github.com/Farhad030619/cisco-netaudit-engine)
Enterprise network automation and security compliance framework for Cisco IOS/IOS-XE. Uses YAML data models and Jinja2 templates to generate standard device configurations, coupled with an automated CIS benchmark auditor evaluating 10 critical security standards with terminal remediation output.

### [NetLens-Recon](https://github.com/Farhad030619/NetLens-Recon)
Asynchronous attack surface mapping and visual reconnaissance tool. Combines high-concurrency port probing via aiohttp with automated Playwright browser viewports, perceptual image hashing (dHash) for visual deduplication, and heuristic high-value target classification.

### [PCAP-Parser-Intrusion-Detection](https://github.com/Farhad030619/PCAP-Parser-Intrusion-Detection)
Network traffic analyzer and signature-based IDS built with Scapy and Python. Detects SYN flood DoS attacks, ARP spoofing, DNS tunneling exfiltration, and port scan sweeps with an asynchronous FastAPI and WebSocket monitoring dashboard.

### [soar-incident-responder](https://github.com/Farhad030619/soar-incident-responder)
Security orchestration, automation, and response engine parsing network CSV/JSON logs, querying threat intelligence via VirusTotal v3 API, and generating firewall enforcement rules for Cisco ASA and Linux iptables.
